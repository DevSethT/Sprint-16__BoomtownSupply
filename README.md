# Boomtown Website

A modern, scalable web application for showcasing vape products and store locations.

---

## Overview

Boomtown is a full-stack web application designed to provide users with an intuitive way to explore vape flavors and find nearby store locations. The app focuses on scalability, clean UI, and real-world usability by allowing businesses to manage products and locations dynamically instead of hardcoding content.

This project was built as a final project for the TripleTen Software Engineering Bootcamp and demonstrates real-world development practices including API integration, dynamic rendering, and responsive design.

---

## Features

- Dynamic Product Display
  - Displays a full catalog of vape flavors
  - Data-driven (no hardcoding)

- Store Locations System
  - Shows multiple store locations
  - Highlights the closest location to the user with fallback logic

- Interactive Map (Optional)
  - Displays user location and store markers

- Scalable Data Structure
  - Easily add, edit, and remove products and locations
  - Designed for future admin functionality

- Responsive Design
  - Works across desktop and mobile devices

- Modern UI/UX
  - Clean layout inspired by real business websites
